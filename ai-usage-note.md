I didn’t code anything by hand. I chose not to because I didn’t see a need to. The coding agents write code faster and more accurately than I would by hand, and where I add the most is architecture and system design. So that’s where I spent my time, along with reviewing what they built. I decided the workflow, the architecture, how the Guava SDK should be integrated, the routing logic, and where the agent should be agentic versus deterministic. I scoped the application. I designed the two adapters, one for the SDK and one for the GEICO API, so each can grow without touching the other. I designed the golden evals to judge performance, and I added edge-case tests the coding agent had missed in the offline suite. I also built the checklist, which was meant to be my KPI. I designed it to make adding new scopes to the agent easier, but I couldn’t measure that in the time I had. The coding agents wrote the code, following my instructions and the harness I maintained throughout the build. I used them to brainstorm and to check my ideas too. For example, when I came up with the supervisor model (one model talks, one watches the call, and code decides), I told Claude exactly how it should work, it confirmed the design held up, and then I narrowed its scope so it could ship before code freeze.
Where they went wrong, I caught it. While mapping workflows, Codex produced 94 separate scopes, which wasn’t realistic, so I stopped the build, opened a Word doc and worked it out myself. I grouped them into a few broad caller scenarios and listed the conditions that make up a happy path. A path becomes hard when one of those conditions is missing or uncertain. That’s how I came up with the checklist, and it’s why I think it makes adding scopes easier: I reverse-engineered it from those 94. Later, the golden evals came back red on several scenarios, including the happy path, and the agents started debugging code to fix them. I stopped them and read the transcripts myself, and it was obvious the eval scripts were stale: the scripted caller never answered the safety question I had added, so the agent was failing a test that no longer matched the build.
